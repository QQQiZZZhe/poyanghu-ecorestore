# 鄱阳归翎：生态修复手记

一款生态卡牌策略游戏。你是湿地守护站的站长，要在 16 回合的四季循环里分配有限的预算，
同时压住水位、水质、沉水植被、鱼类、候鸟、社区这六项指标——任何一项跌破红线，这一年就结束了。

四季的时间感参照二十四节气压缩而来：现在放水能缓解洪涝，代价是水位降下去、沉水植被跟着少；
这一季省下的预算，可能变成后一季某个危机爆发的引线。危机提前一回合预告，你有反应的时间。

Godot 4.7 制作，四人团队，Windows 与 Android 双端可运行。

## 玩法

- 55 张行动卡 + 41 张科普知识卡，四档难度
- 六项生态指标互相拉扯，危机提前一回合预告
- 16 回合的四季循环，预算在季节之间滚动

## 我在这个项目里做的事

主策划兼副程序：规则框架、危机事件、55 张卡的配置与数值、四档难度、全部文案与知识卡；
用 AI 脚本跑自动对局做平衡验证（3,200 局、按难度与打法分组对照，困难档存活率 57% → 74%，
噩梦档 20% → 39%）；程序框架、美术与科学内容由团队其他成员负责。
